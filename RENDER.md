# Host CUE on Render + keep Uno listening

## Important

**Render cannot see your USB ports.**  
Hosting on Render = website + API in the cloud.  
The **Uno agent on your Windows PC** keeps listening on any COM port and posts data to Render.

```
[Uno USB any port] → [PC: scripts/uno_agent] → [Render CUE API] → [Browser dashboard]
```

## 1. Push this repo to GitHub

Use the `cue` repo (or push `backend/` + `render.yaml`).

## 2. Deploy on Render

1. [Render Dashboard](https://dashboard.render.com) → **New** → **Blueprint**
2. Connect the GitHub repo that contains `render.yaml`
3. Apply the blueprint (creates **cue-api** web service + **cue-db** Postgres)
4. After first deploy, open the service URL (e.g. `https://cue-api-xxxx.onrender.com`)

### Create admin user (Render Shell)

```bash
cd backend   # if shell starts at repo root
python manage.py createsuperuser
# or:
python manage.py shell -c "from accounts.models import User; User.objects.create_superuser('cueAdmin','admin@cue.local','CueAdmin@2026', role='ADMIN')"
```

### Provision Uno API key (Render Shell)

```bash
python manage.py provision_uno_agent --api-base "https://YOUR-SERVICE.onrender.com/api/v1" --write-config
```

Copy the printed `api_key` into your PC’s `backend/scripts/uno_agent/config.json`.

## 3. Always-on listening (your PC)

```powershell
cd backend\scripts\uno_agent
# edit config.json → api_base = https://YOUR-SERVICE.onrender.com/api/v1
.\install_windows_autostart.ps1
```

Plug the Uno into **any USB port** — the agent auto-connects and keeps running after login.

## Env vars (set in Render if needed)

| Key | Notes |
|-----|--------|
| `DJANGO_SECRET_KEY` | Auto-generated by blueprint |
| `DEBUG` | `False` |
| `DATABASE_URL` | From Render Postgres |
| `MSINGI_API_KEY` | Optional TTS |
| `TEXTSMS_*` / `ALERT_PHONES` | Optional SMS |

## Local test of Render build

```powershell
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open http://127.0.0.1:8000/ for the UI (same process as API).
